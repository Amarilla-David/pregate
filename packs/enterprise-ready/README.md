# Enterprise-ready

An optional preview pack for multi-tenant products bought and operated by enterprise
customers. Its 57 independently identifiable evidence gates retain the original
requirements and conditions. Select `enterprise-ready/readiness`; use `--only`
for an explicitly reviewed subset. No certification is issued by this pack.

Read the [requirements](../../docs/features/enterprise-ready-pack.md) and
[adoption/evidence guide](../../docs/guides/readiness-packs.md). Missing product
assertions stay unverified. Receipt fixtures test evidence admission, not 57
production behaviors. The bounded isolation example tests only its declared paths.
